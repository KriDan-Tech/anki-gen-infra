## Схема ответственности

Frontend проводит пользователя по пути загрузка → страницы → цена → оплата → результат; gateway проверяет JWT и направляет HTTP; Keycloak отвечает за идентичность. Billing владеет внутренними кредитами, каталогом тарифов и учётом операций. Source-service принимает PDF, извлекает текст/геометрию/OCR и хранит страницы/чекпоинты. Vocab-extractor извлекает слова, сохраняет работу и использует AI; заголовки — только в historical frozen profiles; card-builder обогащает слово переводом/чтением; deck-service владеет карточками, тегами, колодами и экспортом. Infra описывает compose и эксплуатационные зависимости. Межсервисные события и HTTP-контракты проверять в версиях исходников и focused docs, не выводить контракт из этой схемы.

PDF — чувствительный входной материал. Жизненный цикл файла/результатов зависит от владельца каждого хранилища и стадий завершения; не обещать удаление или сохранность по одной только общей схеме. Сверяйте конкретные durable-file и checkpoint реализации.
